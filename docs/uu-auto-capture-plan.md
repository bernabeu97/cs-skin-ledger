# 悠悠一键抓取助手 立项文档（二期，未排期）

## 1. 背景与目标

现状：UU（悠悠有品）记录通过「Chrome 扩展导出 JSON → 网页选择文件 → 比对预览 → 确认导入」完成，需两步手动操作。
目标：用户在已登录悠悠的浏览器中点击一次，自动抓取交易记录并增量提交到云端账本，与现有幂等导入/对账能力打通。

## 2. 功能说明

- 网页账本页提供「一键同步」按钮；首次使用展示安装引导。
- 浏览器侧助手（扩展或本地小工具）在用户已登录悠悠的会话中抓取「全量记录 JSON」（与现有 exporter 输出同构）。
- 自动调用现有接口：`POST /api/sync/uu/preview-full-json`（比对预览）→ `POST /api/sync/uu/import-full-json`（增量入库）。
- 完成后回传结果并展示：新增 / 重复跳过 / 未匹配卖出 / 金额不一致建议。

## 3. 技术方案（两个候选，二选一）

| 方案 | 说明 | 优点 | 缺点 |
|---|---|---|---|
| A. Chrome 扩展（推荐候选） | 基于/改造 [youpin898-record-exporter](https://github.com/bernabeu97/youpin898-record-exporter)，在已登录会话中抓取并 POST 到账本 API | 用户侧无需安装额外工具；复用现有导出数据结构 | 需要维护扩展；扩展抓取可能受悠悠页面改版影响；需处理跨域与 CSRF |
| B. 本地同步器 | 桌面端/命令行小工具，用户浏览器登录后手动导出文件由工具监听上传 | 与桌面端生态一致 | 仍是半自动；额外安装与分发成本 |

推荐：先做 A 的最小可用版（仅抓取全量记录 JSON 并上传，UI 沿用现有预览弹窗）。

## 4. 风险与限制（不承诺，仅记录）

- **平台合规/账号风控**：自动抓取违反悠悠平台条款的可能性高，可能触发风控；使用前需在页面展示免责提示。
- **WAF 拦截**：`api.youpin898.com` 服务端直连已被阿里云 WAF 拦截（403），本方案只从浏览器侧抓取，仍可能受网页端风控影响。
- **数据口径限制**：UU 网页版无物品级完整交易明细（订单管理为 APP 专属），金额/物品缺失部分继续按「待补填买入价/未匹配卖出」处理，不虚构数据。
- **扩展维护**：悠悠页面结构变化会导致抓取失效，需要持续维护；建议把解析逻辑与 UI 分离，便于快速修复。

## 5. 排期建议

- 一期（本轮，已完成）：比对预览、双向对账、批量补填、幂等导入 —— 已上线。
- 二期（未排期，约 3-5 天）：扩展骨架 + 抓取 + 上传 + 安装引导 + 免责提示。
- 三期（可选）：监听文件自动上传、通知渠道接入（Webhook/邮件，需产品确认）。
